# Grass Field: трава с ветром для мобильных

Сцена `Assets/_Project/Scenes/GrassField.unity`, пересборка: `Tools/Portfolio/Build Grass Field`.

| Решение | Зачем |
|---|---|
| Форма травинки - геометрия (7 вершин, 5 треугольников), без альфа-текстуры | Шейдер непрозрачный, без `clip()`: на Mali/Adreno/Apple работает ранний z-test, нет overdraw от прозрачных краёв |
| Чанки 4x4 м, каждый - один экземпляр меша, `Graphics.RenderMeshInstanced` | Всё видимое поле - 2 draw call (LOD0 и LOD1), без GameObject на чанк |
| LOD1 - каждая 4-я травинка, вдвое шире, 1 треугольник | Вдали в 9 раз меньше вершин, переход читается как разрежение |
| Куллинг по фрустуму и дистанции на CPU, сортировка от ближних к дальним | Без compute-шейдеров: работает на GLES 3; ближние травинки закрывают дальние до фрагментного шейдера |
| Исчезновение вдали - травинка сжимается к корню в вершинном шейдере | Без альфа-блендинга и без "выскакивания" на границе дальности |
| Ветер: бегущий шум (порывы волнами по полю) + синус с фазой травинки + поперечный трепет | Одна выборка текстуры в вершинном шейдере, корень неподвижен, длина травинки сохраняется |
| Данные травинки (корень, два случайных числа) в TEXCOORD1 | Ветер, цвет и исчезновение без дополнительных текстур и буферов |
| Свет: wrap-освещение, просвет против солнца, затемнение у корня | Дешёвая замена subsurface scattering и AO |
| Нет ShadowCaster, тени только принимаются, без soft-вариантов | Минус проход по тысячам травинок в shadow map, меньше shader variants |
| Ветер и отталкивание - глобальные параметры (`GrassWind`, `GrassInteractor`) | Вся растительность сцены качается согласованно |

Цифры (ПК, только проверка работоспособности): ~50 тыс. травинок в кадре, 2 draw calls. Замер на Android: `Tools/Portfolio/Build/Android - Grass Field`.
