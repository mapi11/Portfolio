# Winter Glade: cartoon зимняя поляна

Сцена `Assets/_Project/Scenes/WinterGlade.unity`, пересборка: `Tools/Portfolio/Build Winter Glade`.

## Toon-шейдер (`Portfolio/Toon/Lit`)

Один шейдер на ёлку, камни, траву и снежную землю.

| Решение | Зачем |
|---|---|
| Цвет объекта в vertex color, без текстур альбедо | Ёлка, камни и трава делят материал, нет выборок альбедо |
| Ступенчатый свет, тень тонирована холодным синим | Мультяшная подача: тень не чёрная, а «нарисованная» |
| Снег по нормали с рваным краем из шума, альфа vertex color запрещает снег (низ веток, ствол) | Снежные шапки без отдельной геометрии и масок |
| «Раздутые» нормали ярусов ёлки (от центра яруса) | Свет ложится мягкими пятнами, как на рисунке |
| Искры снега: два слоя белого шума, второй сдвигается от взгляда | Искры вспыхивают при движении камеры, 2 выборки текстуры |
| Отключённая фича — это 0 в параметре, без keyword-ов | Нет взрыва shader variants |

## Лёд (`Portfolio/Toon/Ice`)

| Решение | Зачем |
|---|---|
| Непрозрачный, без opaque/depth texture и отражений | Дёшево на мобильных, нет лишних проходов |
| Трещины и пузырьки на трёх «глубинах» со сдвигом параллакса от взгляда | Объём толщи льда без прозрачности; мировые XZ как UV — касательные не нужны |
| Иней у берегов по UV поперёк русла | Мягкий переход ко снегу без depth fade |
| Жёсткий блик и диагональные штрихи-блики | Узнаваемый мультяшный лёд |

## Сцена

- Рельеф, русло, ёлка, камни и трава генерируются кодом; трава из-под снега — один меш на всю поляну (1 draw call), без движения.
- Снегопад — одна система частиц: 110 снежинок/с, до 1500 частиц, шум вместо физики.
- Тени отбрасывают только ёлка и камни.
